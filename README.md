# 🐱 Knowledge Pet · 知识收藏桌宠

电脑右下角常驻一只猫咪，**一键收剪贴板 → AI 整理成知识卡**。

> 灵感组合：「桌宠陪伴」+「剪贴板快捕」+「AI 知识管理」，纯本地 Markdown + Git 友好。

## ✨ 功能

| 操作 | 效果 |
|---|---|
| **单击猫咪** | 收集剪贴板内容（自动判断网址/文本），嘴角冒泡 📥 确认 |
| **双击猫咪** | 打开知识收藏面板（统计 / 筛选 / 抓取 / AI 整理 / 设置） |
| **网址收藏** | 自动进抓取队列，定时爬取正文 |
| **AI 整理成卡** | 调用你配置的 API，生成「一句话结论 / 展开 / 下一步行动」知识卡 |
| **状态流转** | 🌱新收 → 📄已爬正文 → 👁已读 → ✨已成卡 |
| **托盘常驻** | 关闭面板只是隐藏；托盘双击/右键唤起面板 |
| **全局热键** | 默认 `Ctrl+Alt+C` 任意窗口一键收剪贴板（设置页可自定义） |
| **常用网址** | 面板底部维护常用网址，一键打开 |
| **知识库迁移** | 设置页可把知识库整体迁到任意目录 |

- 收集的内容落在本地知识库 `~/knowledge-base/`（`10-inbox` 收件箱、`30-notes` 知识卡）
- 纯 Markdown 文件，随时可用 Git 管版本、用 Obsidian 等编辑器打开
- AI 配置存本地 `.pet-config.json`，不上传、不打包

## 🛠 技术栈

Tauri 2 + Vue 3 + TypeScript + Rust（reqwest / serde），零重型依赖。

## 🚀 从源码运行

```bash
# 前置：Node.js 18+、Rust（MSVC toolchain + VS Build Tools）
npm install --registry=https://registry.npmmirror.com
npm run tauri dev      # 开发模式
npm run tauri build    # 打包 exe
```

## ⚙ 配置 AI

面板 → ⚙ 设置 → 填 OpenAI 兼容接口三项（base_url / API Key / 模型名）→ 保存。
任何 OpenAI 兼容服务均可（如 `https://api.xxx.com/v1`）。

## ✍️ 知识卡工坊（v0.3）

收藏只是开始，用起来才算数。面板新增三个区块：

| 区块 | 功能 |
|---|---|
| **🐱 每日冒泡** | 按日期轮换抽一张知识卡 + 列出未完成的「下一步行动」，提醒你把收藏变成产出 |
| **💡 跨卡选题** | AI 把知识卡两两组合、跨领域碰撞，提炼 5 个值得写的选题 |
| **✍️ 引用创作** | 勾 2-5 张知识卡 + 写作任务 → AI 生成草稿存 `50-drafts/`，frontmatter 记录用了哪些卡（引用快照） |

草稿铁律：观点和事实尽量引用知识卡原句，卡里没有的数据一律不写、不编造。
草稿的 `used:` 字段保存了当时所用卡片列表——原卡以后修改或删除，草稿可回溯依据。

## 🔌 集成（v0.4）：Notion + 飞书

设置页拆成 4 个标签：🤖 AI 模型 / ⚙ 通用 / 📖 Notion / 💬 飞书。

**Notion（手机学习入口）**：设置 → Notion 标签，填 Internal Integration Token（ntn_ 开头）+ 数据库 ID，测试连接后可预览数据库最近记录。第二期将支持拉取 Notion 新行 → AI 整理成本地知识卡。注意：必须在 Notion 数据库页面 ••• → 连接 里把 integration 加进去，否则报 404。

**飞书（手机复习/提醒通道）**：飞书群 → 设置 → 群机器人 → 添加自定义机器人 → 复制 webhook 填入 → 可发测试消息、立即推今日冒泡。开启开关后每天 9 点自动把「每日冒泡」（今日知识卡+待办）推到飞书群。


## v0.8 微信文章采集（借鉴 wechat-url-capture）

在微信里刷过的公众号文章，一键捞进知识库：

- **📥 微信文章采集**（面板新区块）：
  - 🔍 **抓取浏览记录**：读取微信本地 Chromium `History`（未加密 SQLite，只读复制，不碰微信进程），列出最近 7 天看过的公众号文章（标题/公众号/时间），小程序与普通网页自动过滤
  - 📥 **存收件箱**：勾选后存 `10-inbox/微信文章/`，frontmatter 带 `url:`/`author:`/`visited:`
  - 🤖 **AI 成卡**：勾选后 AI 按「待补全」格式生成知识卡到 `30-notes/`
  - 📤 **导出公众号**：汇总最近 90 天文章的公众号（biz+名字）导出 `exports/gzh-sources.json`，给评论寻客「导入来源」用
- 自动去重：知识库已有的 URL（frontmatter `url:` 匹配，按 `__biz+mid+idx+sn` 归一）不会重复入库
- 要求：Windows + 微信 4.x（xwechat）。只在微信里打开过的文章才会被记录
